# SuenMeow 2

独立实现的 Discourse 猫咪伙伴。中文控制台配置人格、回复节奏、四条模型路由、记忆、人工审核和猫窝；所有论坛写入统一限速，仅回复既有主题或既有私信。

## 开发

需要 Python 3.12+、Node 22+；正式部署使用 PostgreSQL。SQLite 仅用于本地快速验证。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/suenmeow init
PUBLIC_ORIGIN=http://localhost:5173 .venv/bin/uvicorn suenmeow.api:create_app --factory --host 127.0.0.1 --port 8000
```

另一终端：

```sh
cd frontend
npm ci
npm run dev
```

打开 `http://localhost:5173`，使用初始化时的管理员账户。生产密钥不能用于本地界面演示。普通用户通过论坛私信验证码证明身份，首次进入自动创建受限编辑者；使用真实论坛昵称及头像。管理员可关闭首次注册或逐模块授权，原管理员密码入口保留。

私信验证不依赖论坛管理员，不收集论坛密码，也不调用模型或由机器人回复。流程与验收见 [论坛私信登录](docs/REGISTRATION.md)；生产已关闭无身份的网页自由注册，用户已亲自完成真实验证码私信与登录验收。

人格与提示词在同一工作区编辑和编排。右下角保存栏显示未保存状态，支持 ⌘/Ctrl+S；人格默认保存后生效，可由管理员开启审核；系统提示词和全局编排仍保存为草稿，由管理员发布。保存冲突不会覆盖他人修改。编辑者可创建、复制、编辑自己的/获授权的模块，删除自己的未被编排引用的模块；不能发布、改全局编排或模型连接。

## 部署

```sh
python3 tools/prepare_deploy.py --origin https://suenmeow.example.com
docker compose build
docker compose up -d database
docker compose --profile setup run --rm init
docker compose up -d api worker gateway
```

网关仅监听服务器 `127.0.0.1:8000`；通过已有 HTTPS 反向代理或隧道公开访问。数据库没有主机端口。首次运行默认暂停。

管理员用户名为 `admin`，初始密码保存在服务器 `secrets/admin.password`。`secrets/` 目录权限为 0700；Compose 仅把需要的单个文件挂载到相应容器。不要提交 `.env`、密钥、密码或数据库。备份数据库时也必须同时备份加密密钥，否则无法解密保存的连接与私信数据。

先设置连接、检查 prompts 编排并发布，开启只读模式检查新水位，再选择审核或自动模式。修改连接自动暂停；重启、重连、模式切换和发布后重新跳过积压。原草稿不能强制补发。发送超时进入“待核实”，管理员在论坛核实后标记结果，系统不重试原事件。

## 个人贴记忆

用户在记忆书架一键研究「個人帖」分类（默认 ID 22）中本人的全部公开发言，找不到时填链接。首次从首楼开始，超长原文完整拆段；后台自动研究并整理，显示完整进度，失败可手动从断点继续。取消近期300楼抽样、旧历史省略及个人12,000/20,000 token上限，保留管理员全站日额度。统一核验后自动保存，用户查看来源并删除；后续只处理更新，无新增零调用。见 [全量个人贴研究](docs/MEMORY_IMPORT.md)。

回复不会发送整本书架：先按身份/主题与私信边界过滤，再按当前话题做本地关键词排序、来源核验，最多六条、每条 300 UTF-8 字节；相关资料优先，最多补充两条背景事实。Agent 另可主动查询。当前没有语义向量检索，见 [记忆检索与限制](docs/MEMORY_RETRIEVAL.md)。

## 整帖阅读

侧栏「整帖阅读」支持公开主题一键导出 Markdown/JSON（不调用模型），或完整研究所有人的可见发言后生成总结与点评，附真实楼层链接。长帖在后台自动分段，失败保留进度并可手动继续；不自动回帖、不写入记忆。用量、完整性与权限见 [整帖阅读说明](docs/TOPIC_READING.md)。

## 猫窝

先由用户在论坛创建个人主题，再在 GUI 绑定其 ID 与创建者。可放置小物件、便签和连续小活动。全局趣味互动与猫窝日记都开启时，最多每天一次主动回复；安静时段不发，不补发。私信只绑定已有对话，跟进同一未完理由最多一次，对方沉默就停止。个人私信记忆仅用于原对话。

## 设计与迁移

管理员可在“与猫交谈”页交代研究任务，查看进度、真实来源和草稿。写回复时填写唯一既有主题 ID、可选楼层与字符上限；默认预览，确认当前正文后才进入发送门。暂停时可以研究。改变目标需创建新任务；编辑草稿撤销原批准。自动研究默认关闭，可在研究策略中调整工具和预算。

在“连接与模型”配置支持原生工具调用的可选 Agent 路由；没有专用路由时使用明确支持工具调用的规划模型。模型地址可选择基础地址或完整请求端点；旧配置导入保留完整端点语义。实际模型和论坛的兼容性以验收记录为准。

思考模型的推理可能占用输出上限。“思考强度”默认沿用提供方设置；长文被截断时可选择低强度并提高最大输出 token，仍受任务与每日预算约束。Agent 仅使用已发布、已标为人格的模块作为语气设定，不沿用普通回复路由的旧规划协议。草稿显示有效期及发送受阻原因；只读或过期时不能确认发送。
