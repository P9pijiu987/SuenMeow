# SuenMeow 2 实施规格

状态：实施中。本文记录已确定的重写范围；只有验收记录能证明功能完成。

新增 Agentic 设计见 [主动研究与管理员指令](AGENTIC.md)：跨帖阅读、论坛内搜索、按权限主动检索记忆、管理员聊天台及单条长回复。A1–A5 已接入代码，按交付物与通过条件继续联调和生产验收。管理员任务与论坛自动研究分开，复用预算、隐私和统一发送门。

## 产品目标

独立重写旧版，保留 Discourse 通知回复、热帖参与、四条模型路由（规划、回复、记忆、摘要）、人格与提示词编排、预算、审核、用户和主题记忆、运行日志以及 Docker 部署。旧代码仅用于确认行为，不复制实现。删除旧调试入口、重复编辑器、匿名公开写入及生成目录。

新版控制台使用中文，支持桌面与手机。首页解释机器人现在做什么、为什么没有回复及下一步；策略、提示词、模型、记忆、审核、猫窝和权限均通过 GUI 配置。表单提供范围校验、保存反馈、密钥遮罩、发布记录和回滚。

首帖前的工作提示词更新见 [系统工作提示词](SYSTEM_PROMPTS.md)：保留所有 persona 内容和元数据，统一规划、正文、记忆和内部摘要协议，并增加可发布的 Agent 工作规则。系统模块与全局编排保存为草稿；人格和个人贴编排采用默认关闭的可选审核流程。

## 架构

- Python FastAPI：鉴权、配置与内容管理、审核和只读状态查询。
- 独立异步 worker：读取发布快照，接收事件，规划、生成、发送并异步更新记忆。
- PostgreSQL：配置版本、权限、事件收据、回复、记忆、预算账本和审计记录。
- React + TypeScript：独立构建的控制台；网关提供静态文件和 `/api` 反向代理。
- Docker Compose：网关、API、worker 和数据库；保留旧部署以便回滚。无需 Redis。

Agent 执行器作为 worker 内独立任务处理模块，通过工具注册表使用论坛与记忆适配器；不提供 shell、任意 SQL 或任意 HTTP 执行能力。管理员聊天会话持久化并加密，有界研究轨迹通过 SSE 展示。

客户端与服务分层，论坛、模型提供方可以替换。配置发布为不可变快照；正在处理的事件保留其版本。数据库迁移版本化。

## 鉴权与发布

普通用户采用论坛私信无密码登录：浏览器生成五分钟验证码，用户给 SuenMeow 发一条新二人私信，服务器按真实作者及稳定用户 ID 核验，再由原浏览器确认。首次创建受限编辑者并同步昵称/头像，不能自选角色或授权；每地址每小时 10 次、全站 120 次、最多 100 个有效请求及 500 个账户。生产关闭无身份的网页自由注册，原管理员/旧账户密码入口保留。已有 TOTP 的绑定账户仍须验证；新论坛账户的独立 TOTP 设置流程待实现。服务端会话有过期、吊销、同源/CSRF 检查；Cookie 使用 HttpOnly/SameSite，公开 HTTPS 使用 Secure。密钥加密保存，API 不回读密码或密钥。详见 [私信身份验证](REGISTRATION.md)。

管理员管理策略、模型、账户、授权和发布。编辑者仅能编辑自己或被明确授权的提示词模块，不能用客户端参数绕过权限。人格和个人贴编排默认保存后生效，管理员可开启审核；系统提示词和全局编排仍须管理员发布。公开入口是有鉴权的控制台；关闭旧匿名编辑器。日志不包含密码、密钥及完整私信。

人格与提示词采用模块书架、行内编辑、路由编排的同一工作区。可搜索、筛选、复制、新建模块，按五条路由调整顺序；切换模块保留所有未保存内容。多模块与编排在单一事务内保存，按模块版本和编排版本检测冲突；任一项失败则全体回滚，界面保留修改。右下角恒定显示保存按钮与未保存状态，支持 ⌘/Ctrl+S，离开页面与刷新时提醒。策略页采用相同保存栏，未保存时禁止发布/回滚；连接、猫窝和账户编辑弹窗也有悬浮保存与关闭确认，各自明确提示立即生效或暂停运行的影响。

编辑者最多拥有 50 个模块，整个书架已有 500 个模块时禁止编辑者继续创建（管理员可整理或扩容）。编辑者可删除自己未被当前编排引用的模块，不能删除获授权的他人模块；管理员删除时一并移除草稿编排引用。删除不会修改既有发布快照。论坛身份由私信证明的站点 + 用户 ID 唯一绑定；旧手动同名绑定须管理员迁移，不能自动接管。未绑定账户不能冒领记忆或个人贴编排；猫窝仅由管理员设置。

首条真实回帖之前必须完成公开注册、受限编辑、管理员编排、固定保存栏、并发冲突保护与桌面/手机验收。私信登录已实现并通过模拟/HTTPS 边界检查，用户已亲自完成真实验证码私信与登录验收。拟人回复、逐帖 reaction 判断和约三分之一互动率改革见 [互动改革](INTERACTION.md)，同样纳入首帖前交付，当前仅完成设计。部署和保存不会自动开启发送，验收期间继续只读。

## 回复与发送的硬约束

运行模式：暂停、只读、审核、自动。通知约每 5 秒检查，热帖约每 60 秒检查；可在 GUI 调整。预算不足、冷却、静音、封禁、过期或权限不足均有明确原因。

每次启动、登号、重新登录、从暂停恢复或断线超过 60 秒恢复时，先建立论坛通知和主题水位，再接收新事件。旧通知、旧草稿和已过期事件不因上线而自动发送。热帖水位按主题推进，不能永久阻止该主题后续的新活动。

所有发送经过一个入口，仅回复既有主题 ID，包括既有私信。不得创建新主题或新私信。逐条收据去重；默认全局间隔 60 秒、同主题间隔 10 分钟、事件有效期 10 分钟。人工审核也必须通过同一发送门。发送结果不确定时标为待核实，禁止自动重发；记忆更新失败不得重发已发送内容。

四条模型路由统一预算：调用前预留、调用后按提供方真实 token 用量结算，失败与无用量结果保守记账；每天重置，不沿用旧版固定估算。

## 从个人贴建立用户记忆

已验证论坛身份的用户在记忆书架一键研究本人「個人帖」分类中的全部公开发言；找不到时填链接，服务器核对分类与首帖稳定作者 ID。首次从首楼开始，不沿用旧近期覆盖水位；原文完整拆段，后台多次研究、整理和来源复核，统一保存并提交全量水位。取消近期300楼、省略旧历史和个人12,000/20,000 token限制，保留全站日额度与原子记账。显示完整进度，已完成段落加密保存；中断不自动重试，用户可从断点手动继续。后续只研究更新，无新增零调用；删除事实保留来源指纹。管理员可在GUI设置来源分类。来源变化停止公开使用，按站点与用户ID归属，七个人格不改。详见 [个人贴研究](MEMORY_IMPORT.md)和[记忆检索](MEMORY_RETRIEVAL.md)。

## 让猫更好玩

猫窝是 SuenMeow 自己的单一公开个人贴，由管理员设置；所有登录用户只读查看，不能绑定或修改。保存、生成、最终发送前核验机器人稳定用户 ID 等于首楼作者 ID，且主题公开、未关闭或归档。旧用户猫窝不再生成事件，旧待发事件被共享发送门拒绝，原记录保留。

默认关闭，支持虚拟生活设定、小物件、小活动和空闲时间（15–1440 分钟，默认 120）。全局策略发布、猫窝单独开启后，在当地 10–21 点且安静时段外、无待处理回复时尝试写独立的虚构日常或感想。全站按日期去重，每天至多一次尝试，可选择不写；不要求有访客，不定向回复旧楼层。启动/恢复重新等待，不补日记。不读取用户记忆或私信、不启动跨帖研究、不提取日记为用户事实。沿用共享预算、冷却、审核和不确定发送保护。猫窝不再承载私信主动跟进，常规私信回复继续原流程。详见 `CAT_NEST.md`。

## 迁移和上线

从 MacBook 的实际部署读取凭据、模型连接和保存的 prompts；文件传输不回显敏感内容。不导入旧记忆、事件、待发队列和历史水位。先制作受限访问备份，再进行离线迁移，校验导入数量与内容。

本地、模拟论坛和 API 权限测试通过后，部署至同一 MacBook。上线默认暂停，验证公开入口、健康状态、资源占用和水位建立后才开启处理。首次上线保持发送限速。共享隧道的其他服务不得受影响。

## 个人贴专属编排

所有登录用户只读浏览全部人格及全局编排；本人和授权模块编辑权限保持原样。用户为经论坛身份核验的本人公开个人贴建立五路人格编排，默认保存后生效；管理员可开启同时涵盖人格与个人编排的审核开关。管理员始终查看全部用户编排。仅绑定的站点/主题/首帖作者应用，工作规则、预算和发送门保持管理员控制；私信及其他主题使用全局编排。人格发布只刷新已生效使用，不发布系统规则或全局编排草稿；停用、重新发布或身份/连接变化使旧发送草稿失效。见 [TOPIC_PIPELINES.md](TOPIC_PIPELINES.md)。

## 整帖阅读

新增用户发起的公开主题全文导出及完整总结/点评，所有参与者可见原文均纳入。导出零模型调用；模型研究完整分段、分层整理，支持关注重点、出处、用量和手动断点恢复。结果仅在本人网页任务显示，不自动发送或建立记忆。边界、额度、接口和提示词发布语义见 [TOPIC_READING.md](TOPIC_READING.md)。
