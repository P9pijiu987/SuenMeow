## 验证层次

1. 单元测试：发送门、预算、权限、提示词编排、隐私和时间边界。
2. API 集成：真实数据库事务、会话、表单校验、发布和审核。
3. 浏览器：管理员与编辑者完整流程、窄屏、空状态、错误和恢复。
4. 模拟论坛：启动积压、并发事件、网络超时、进程崩溃和记忆失败。
5. MacBook：容器、持久化、资源、公开入口和迁移计数；不以大量真实回复进行测试。
