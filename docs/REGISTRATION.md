# 私信注册与论坛身份绑定

状态：2026-10-04 新增设计，尚未实现或发送注册私信。现有网页注册已经部署：用户名及至少 12 字符的密码，立即获得受限编辑者账户；论坛身份仍由管理员绑定。本方案需要在首条真实回帖之前完成并验收，不能在发布介绍中称为已上线。

## 用户流程

默认设计采用**自然语言申请、网页设置密码**。用户给 SuenMeow 发起一对一私信，例如：

> 我想注册 SuenMeow 后台，账号叫小鱼，想一起编辑提示词。

1. 系统读取新的私信及论坛返回的真实作者信息，识别注册意图和可选账号名。不能从正文中自称的身份进行绑定。
2. 在同一条既有私信中回复短时、一次性的激活链接；缺少账号名时可以在激活页填写，不要求用户记住命令格式。
3. 激活页显示已核验的论坛用户名。用户设置后台用户名、密码并确认，服务端原子创建受限编辑者并绑定论坛身份，立即进入工作区。
4. 已绑定用户再次申请时提供登录指引，不另建账户、不改绑定、不重置密码。重命名冲突让用户另选名字；错误提示不泄露其他人的账户资料。

注册不产生管理员权限、全局编排权、发布权或其他用户模块的编辑权。已绑定用户可使用自己的身份参与猫窝等现有功能；权限继续由服务端校验。

## 密码与身份边界

- 推荐入口不要求在论坛留下密码。密码只提交到本站 HTTPS 激活接口，使用 Argon2id 保存；不进入 AI 上下文、论坛回复、审计、记忆或后台聊天。
- 若启用“私信直接填写账号密码”，凭据必须先由本地服务独立提取并移除；识别服务只能接收脱敏资料。提取失败或含义不明时提供激活入口，不能把原文送给模型猜测密码。此模式须单独完成脱敏验收再启用。
- 身份依据为论坛连接、论坛稳定用户 ID 和实际发言作者；用户名只是显示名称。适配器需保留 `user_id`，不能仅使用通知中的 `display_username`，也不能让模型选择绑定对象。
- 首版仅接受含机器人与该发信人的一对一私信；群聊、公开帖、引用他人注册请求及机器人自发消息不创建申请。激活前、发链接前均重检参与者与来源帖子。
- 旧后台账户不能仅凭同名被接管。现有管理员绑定需核验稳定 ID 后迁移；绑定唯一性按论坛站点及用户 ID 检查，禁用账户不能自行重新注册绕过封禁。

## 服务端实现

注册是独立的账户流程，AI 只输出受限的意图与建议名称，不提供创建账户、绑定、授予权限或发送的工具。

| 组件 | 需要实现 |
| --- | --- |
| 论坛适配器 | 保留帖子 `user_id`、作者与 PM 参与者；读取确切触发帖子，校验真实性及私信范围 |
| 注册服务 | 独立申请状态、来源收据去重、身份唯一性、用户/全站限速；事务内创建账户并消费申请 |
| 激活凭据 | 高熵随机值，仅存摘要；15 分钟有效、一次使用、最多一个有效申请；重新申请使旧链接失效 |
| 激活 API | POST 核验来源、凭据及密码；并发消费只能成功一次；GET 仅展示状态，预览爬虫不能消费凭据 |
| 前端 | 私信注册指引、激活页、已绑定身份、错误恢复；链接令牌立即从地址栏移除，禁用第三方资源和 referrer |
| 管理界面 | 注册总开关、网页/私信入口选择、脱敏申请状态、吊销链接；不得查看密码或从申请列表取得激活令牌 |

激活链接绑定单个申请、站点、来源私信和真实用户；建议使用 URL fragment 携带令牌，避免访问日志收到令牌。注册回复仅加密保存必要的待发正文，发送成功后及时清除可恢复令牌。申请过期、关闭注册、封禁、身份冲突或参与者变化时均失效，不自动改绑。

网页直接注册目前继续开放。默认产品方向是在私信注册验收完成后仅开放私信入口，让每个新账户具备真实论坛身份；切换前不能留下无法注册的空档。若保留两个入口，网页账户仍需独立的论坛身份验证，不能自行填写绑定用户名。

## 处理顺序与发送安全

私信注册必须在普通规划、摘要、主动研究和记忆保存之前识别并隔离；注册内容不进入这些流水线。相关来源不能被管理员研究或跨帖工具再次读入模型；系统工作提示词需说明转交注册流程，persona 保持原样。

只处理启动/恢复水位之后的新申请，沿用 TTL、去重和封禁。激活链接只回复申请所在的既有 PM，不新建话题或主动私信。链接发送必须经过共享发送门；暂停/只读禁止发送，审核模式等待明确批准，冷却和未知发送结果不绕过。未知结果不会自动重发，用户主动重新申请才可生成新凭据。

不得以“注册消息”为由提前开启首次真实发送。部署期间使用假论坛完成流程验收；随后才安排受控的一对一真实私信测试，核验唯一回复、绑定和清理，再满足首帖发布条件。

## 必须通过的验收

- 中文自然表达、缺少账号名、同名冲突和普通聊天正确分流；含密码文本不进入任何外部模型请求、日志、记忆或回复。
- 伪造作者、引用请求、公开帖、群聊、其他站点、禁用账户及已绑定身份均不能冒领或重复注册。
- 链接过期、重复消费、并发消费、关闭注册、重新申请与身份变化均有明确结果；不能通过激活接口自选角色或授权。
- 原网页注册、登录、TOTP、CSRF、配额、受限编辑及不可变发布不回退；已有管理员与七个 persona 不变。
- 启动积压、模式切换、审核、网络超时和进程中断不造成大量回复或重复发送；注册回复不触发事实记忆。
- 桌面与手机可完成申请、激活、登录和自己的模块保存；真实测试与模拟证据分别记录到 `ACCEPTANCE.md`。
