# 从个人贴一键建立近期记忆

2026-10-05 修订：用户在记忆书架选择本人个人贴，一键完成读取、提取和保存，随后查看来源并删除不想保留的记忆。主流程不再要求预览确认、勾选候选或手动继续下一批。AI 提取是可纠正的资料，不代表事实绝对正确。

## 分类和身份

只发现「[個人帖](https://forum.rdfzer.com/c/22-category/22)」分类，默认 ID 22。查询为 `user:稳定用户ID in:first category:=22 order:latest`，仅一页、最多 20 个主题结果，核验最多 5 个。分类精确匹配、不包含子分类；分类、公开性与首帖作者 ID 在服务端再次核验，不能靠改请求导入他人的帖子或其他分类。手动链接也遵守相同检查。

管理员可在书架的来源设置调整分类 ID，固定右下角保存栏显示未保存状态；保存立即影响查找和新导入，旧运行任务检测版本变化后停止。查找缓存按用户身份、论坛连接及分类绑定两分钟；失败只缓存 30 秒。查找不调用模型。分类过滤语法见 [Discourse 官方搜索实现](https://github.com/discourse/discourse/blob/main/lib/search.rb)。

## 一次自动完成，近期优先

从最新楼层向前选择资料，最多检查最近 300 个未处理帖子 ID，每次网络读取最多 20 帖。只使用帖主本人的有效原帖；引用、他人评价、系统/隐藏/删除帖、私信、受限主题和凭据排除。选取顺序为最新在前，达到输入预算即停止读取更早内容。工作协议要求优先当前兴趣、长期偏好及正在进行的事情，矛盾时以较新的明确发言为准，避免保存过时临时状态。

用户不用处理内部网络分页。每次导入最多一次记忆模型调用，随后自动核验原句、作者和当前公开性，最多保存八条有来源的事实。书架展示原句、原帖链接及来源日期，用户可直接删除。普通用户仅保存到本人账户；管理员可为未注册用户建立资料，后续真实登录按站点与稳定 ID 归属。

这不是全文历史归档：界面明确显示检查楼层、本人发言数、未覆盖旧内容和长帖截断数。每条原帖最多读取 3,000 UTF-8 字节的开头；实际覆盖范围受总预算限制。近期窗口之外的旧内容不要求继续导入，不声称已理解整个帖子。

## 费用与重复操作

普通用户默认总预留最多 12,000 token、每日最多三次有资料的模型提取/20,000 token，仍受全站、主题与任务预算限制；管理员 API 可设置最高 30,000，GUI 默认仍为 12,000。输入按 UTF-8 字节保守预留，输出最多 2,000 token且受路由上限约束；输出空间与输入共用总预算，不提高用户总额度。事实要求简短，text 最多60字、引用最多80字，按实际 usage 结算。个人额度在数据库预算锁中原子核验。失败、停止和未知用量不会绕过额度。

官方 DeepSeek 的个人贴提取请求显式使用 JSON 输出并关闭额外思考，节省固定输出预算；只影响该提取请求，其他回复、研究以及非官方提供方保持原配置。参数见 [DeepSeek JSON 文档](https://api-docs.deepseek.com/guides/json_mode/)和[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。输出截断或空正文会显示明确原因，只记录安全错误分类及用量，不保存半截 JSON、原始错误响应或思考正文，不自动重试付费请求。旧失败任务不能追溯确认具体输出错误，不能根据通用 RuntimeError 假称已证实原因。

成功后将近期窗口水位推进到最新楼层，较早且未覆盖的内容是有意省略。再次点击仅处理更新，没新增资料调用为零；删除过的资料不会因重复同一批而复活。模型失败、保存前来源失效、取消或重启不自动重复付费；保存和游标单事务完成。历史修改不自动重建记忆。

## 实现与兼容

`memory_import.py` 的 `/start` 提供一键操作，worker 在暂停/只读时也可处理用户主动导入，没有论坛写入或 Agent 发送工具。原预览/选择保存接口暂时保留，供升级前已存在的任务完成或取消；主界面不再展示手动继续分批。

导入载荷加密，记忆保存站点、稳定作者 ID、主题/楼层、原句与服务端来源时间。普通回复与 Agent 使用前重新核验公开性及原句，见 [记忆检索](MEMORY_RETRIEVAL.md)。自动保存仅作用于用户主动选择的事实资料，不授予提示词修改或发布权限。七个人格原样保留。

验收覆盖分类越权、本人身份、最新优先、超长历史预算、省略量、一次自动保存、删除后不复活、保存前来源改变、并发额度、取消和重启。实际部署及模拟/真实证据见 [ACCEPTANCE.md](ACCEPTANCE.md)。
