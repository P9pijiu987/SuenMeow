# 从个人贴一键研究全部发言

2026-10-05 最新修订：用户要求取消近期抽样和节省 token 的限制。记忆书架首次全量研究本人个人贴，从首楼开始，后台自动读取、分段研究、整理来源事实并保存。旧版近期水位不会令旧历史被跳过。用户只需点击一次，随后查看来源及删除不想保留的记忆。

## 分类和身份

只发现「[個人帖](https://forum.rdfzer.com/c/22-category/22)」分类，默认 ID 22。使用稳定作者 ID、首帖与精确分类搜索，一页最多20个候选，核验最多5个。手填链接同样检查本站、公开性、分类及本人首帖作者。管理员可在书架调整来源分类，右下角保存栏显示未保存状态。连接或分类版本变化停止旧任务，编辑者不能借导入修改提示词或发帖。

## 完整覆盖与后台分段

任务固定启动时的全部可见楼层清单，按楼层向后读取，每次网络请求最多20帖；只研究帖主本人的原文。没有300楼窗口、旧内容省略或3,000字节开头截断。超长发言按完整 Unicode 字符拆段，所有部分进入研究；引用块剥离，保留作者在引用外自己的话。不可见/删除/系统帖、其他作者和敏感发言不作为本人事实，界面单独显示本人敏感/无有效原文的过滤数量。

分段是后台执行细节，用户无需继续下一批。每个模型请求按约64,000 UTF-8字节的保守输入/输出预留组织，输出使用管理员所配路由上限；不是整个任务的 token 上限。各段最多提取12条带原句来源的事实，之后每24条做索引式整理，移除明确重复及被新资料取代的状态。整理只能选择已核验候选，不能编造来源；不同整理组之间目前主要作精确文本去重，不宣传为完整语义矛盾合并。整个书架没有旧版八条事实总上限。

旧经历也会研究；历史状态应标明时间，新偏好不能被旧偏好覆盖。全面研究不等于每句闲聊都成为永久记忆，仍只保留有用、能由原句支持的资料。来源可核验不代表模型概括绝对准确。

## 进度、断点和费用

界面显示读取/研究/整理/来源复核阶段、已检查/总楼层、本人原文条数、已研究字数、模型调用次数、过滤数量和实际 token。任务可持续运行最多24小时，避免原两分钟任务超时；每个网络请求仍有超时保护。

移除新全量任务的12,000单次、20,000个人每日和三次提取限制，也不受普通回复的主题日额度阻断。用量仍在共同账本原子预留并按实际结算；管理员全站模型日额度保持有效，耗尽时明确停止并保留断点，不用截断或省略历史来伪称完成。普通回复、Agent 和旧预览任务的预算不变。

成功段落及整理结果保存为加密断点。失败或重启不自动重试付费请求；用户可点“从已完成部分继续”，复用已完成段落，未完成请求可能再次计费。连接/分类/身份变更后不能继续旧断点。最终统一核验来源、保存事实并提交全量水位；失败不提交半本记忆或水位。每次模型调用前重新核验主题仍公开，保存前再次验证全部引用。

官方 DeepSeek 使用 [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)及[关闭额外思考](https://api-docs.deepseek.com/guides/thinking_mode/)的结构化提取协议，读取完整原文的覆盖范围不受这一输出格式设置影响。截断/空正文保留固定错误分类及安全用量，不存原始错误响应或思考文本。

## 增量与删除

只有完整成功研究后才建立新的全量覆盖标记；下一次点击读取新增楼层，没有新增则零模型调用。旧的近期游标仅用于最终并发检查，不证明全文已覆盖。历史修改不自动重建。

删除个人贴事实时记录来源指纹，之后全量补读也不会以相同来源原句重新放回书架；精确文本去重继续有效。该指纹从本次升级开始记录，不能还原升级前已经删除且无来源记录的事实，也不等于语义级永久屏蔽所有改写。

## 实现与边界

memory_import.py 负责身份、分类、开始/停止/手动继续及旧任务兼容；full_memory.py 负责流式分段、加密断点与来源复核。工作规则来自固定发布快照，专用任务协议追加在后。七个人格不修改，没有论坛写入。暂停或只读模式仍可处理用户主动的书架导入。

普通回复仍按相关性检索少量记忆，不把整本书架发给模型，见 [记忆检索](MEMORY_RETRIEVAL.md)。原预览/候选保存接口只用于兼容旧任务，继续受旧预算约束。实际部署、模拟与模型验收分别记录在 [ACCEPTANCE.md](ACCEPTANCE.md)。
