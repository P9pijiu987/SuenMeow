## 为什么提示预算不足

这是 SuenMeow 的 token 限额，不是 DeepSeek 账户余额。2026-10-11 只读核查时，全站每日上限为 **800,000**，当天已有 **132 次实际调用、777,471 token**，剩余 22,529。调用前需要预留输入及最大输出，因此尚有余额也可能无法启动下一次请求。日账按 **UTC** 重置；亚洲台北时间是每天 08:00。

管理员打开 **与猫交谈 → 研究策略 → 预算**，可调整：

- 全站每日上限：所有模型调用共用，保存后立即生效。
- 自动互动每帖每日上限：限制单帖自动开支，保存后立即生效。管理员研究不再共用主题 0 或自动互动单帖的额度。
- 每个新任务预算：限制一次 Agent 研究，适用于新建任务。提高后重新研究，不会自动重跑失败任务收费。

界面显示今日总用量和正在调用的预留；超限错误显示具体层级、上限、已用及本次预留。成功调用按服务商实际用量结算；失败且没有用量时保留预留，避免漏算。全站可设置至 10,000,000、单帖至 1,000,000、新任务至 1,000,000 token；任务工具步骤最多 32、时间最多 900 秒。这些是可调上限，不保证全量研究总能一次完成。此次部署保留线上原额度，未代用户提高预算。

## 已实现的修复

- **少接话、多表情**：未被邀请的文字参与默认只抽样 3%，另有每日和主题/用户冷却；表情目标 33%，仍排除不适合内容及已有表情。有效表情不因普通正文或扩展失败而丢失。
- **目标一致**：选定正文绑定实际来源作者和楼层；Agent 可正确解析同站主题网址及旧楼层，不再把路径中的楼层当主题。来源、可见性、参与者和发送目标再次核验。
- **输出兼容**：兼容数字字符串 ID、空表情、缺失或过长原因；单个异常表情字段降级该条，保留其他合法动作。未知或重复来源仍拒绝整个批次，不猜目标。
- **识图**：支持原生图片输入的模型收到真实图像，不只是 Markdown 地址。官方 DeepSeek flash 别名自动识别；其他兼容模型可在连接页启用“支持图片输入”。论坛附件限大小和数量，私信不加载外站图片，Cookie 不发往外站。
- **明确跨帖读取**：已选中回复的发言明确要求读同站链接时，可启动限定读取研究；非请求式主动研究仍按管理员开关。不成功时说明限制，不能冒称读过整帖。
- **网络搜索**：管理员可启用 `web_search`，固定公开搜索服务返回标题、摘要与网址。私密任务禁用，不发送论坛凭据，不代表已读网页全文。
- **草稿继续交谈**：审核中的 Agent 草稿提供修改要求输入；修订撤销旧批准，保持唯一目标，补读资料后生成新预览，需要再次确认。发送中、已发送、未知结果和已停止旧任务不能借修订重发。
- **提示词即时生效**：正在使用的现有系统模块保存后生成新不可变快照，仅更新明确修改的工作模块，保留其他策略和全局编排草稿。人格仍遵守可选审核；全局编排仍需发布。新水位跳过积压，旧在途结果作废。
- **自动新增记忆**：普通互动的同一次模型调用可提出最多三条稳定本人事实。保存前核对原句、作者、可见性和来源；排除身份验证及敏感资料，重复事实跳过。记忆失败不会撤销回复/表情，也不会重发。可在互动策略关闭。
- **全部记忆**：`memory_read_all` 冻结并核验全部可用目录、自动续读，只有完成才报告总数；普通闲聊仍只取少量相关事实。
