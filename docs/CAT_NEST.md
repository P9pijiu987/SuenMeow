# SuenMeow 的猫窝

猫窝是 SuenMeow 自己的个人贴，只有一个。它可以在这里写虚构的猫咪日常、碎碎念、小活动和感想；论坛用户来串门时，普通回复流程仍可接话。用户自己的个人贴、记忆书架与专属人格编排是另一套功能。

## 配置与展示

- 管理员在「猫窝」设置已有主题 ID、名字、生活设定、小物件、小活动和空闲时间。
- 保存须核验论坛当前机器人身份及首楼稳定作者 ID，并确认主题公开、开放。不能把用户的个人贴或私信绑定为猫窝；系统不会创建新主题。
- 所有登录用户看到同一个猫窝卡片、设定和论坛入口，没有绑定或编辑控件。
- 保存立即应用；还须发布策略中的「开启猫窝日常」并开启猫窝本身。初始不配置、不启用，连接改变后须重新核验保存。
- 即使论坛暂时无法连接，也能关闭已绑定的猫窝；重新启用须再次核验。
- 页面右下角固定保存按钮，提示未保存，支持快捷键与离开保护。

## 闲时日常

默认连续空闲 120 分钟（可设 15–1440）。有待处理事件或待审核/发送回复时不开始；仅当地 10–21 点、安静时段外尝试，每天最多一次，规划器可以放弃。不要求有访客，也不回复旧楼层。不补写错过的日记，启动、连接恢复或重新启用后重新等待。

正文保持既有人格，说明属于角色的虚拟生活；不编造人类经历、关系、私信内容。不主动检索用户记忆、跨帖研究，不把虚构日记保存为用户事实。只读取猫窝近况来避免重复。

生成与最终发送均再次核验机器人首楼作者与公开性；配置版本、论坛连接、管理员资格发生变化时失效。沿用统一预算、冷却、运行模式和不确定发送处理。只读不会发送；审核模式先生成待审核正文。

## 从旧设计迁移

旧版本把猫窝误做成各用户绑定的空间。现已停止扫描这些记录，普通用户旧读写接口拒绝访问；旧待发事件不能发送。旧数据保留供管理员查阅，没有自动挑选用户帖子、迁移日记或开启主动功能。原猫窝私信跟进撤下，常规通知/私信回复继续使用原流程。
