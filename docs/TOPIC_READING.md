# 整帖阅读、导出与点评

## 如何使用

已通过论坛私信核验身份的用户及管理员，在侧栏「整帖阅读」填公开主题网址或 ID：

- **一键导出全文**：读取完成后自动下载 Markdown，零模型调用。可以再下载 JSON；离开页面后在阅读记录重新下载。
- **总结并点评**：可填写关注重点。后台完整读取所有参与者的可见普通发言，再分别生成整帖总结、SuenMeow 的看法及可点击参考楼层。结果仅在网站展示；不自动回复论坛、不写入个人记忆。

研究使用当前主题已生效的回复人格，若没有个人贴编排则使用全局回复人格。人格只影响最后点评语气；系统协议独立，不把普通回帖的规划协议拼入整帖任务。

## 完整性与范围

启动时固定楼层 ID 清单，包含首帖和所有历史，不按年份、最新300楼或作者抽样。后台每批取20楼仅为论坛接口分页，用户不需逐批操作；长正文按完整 UTF-8 边界拆分，所有片段均研究。随后四路逐层合并笔记，避免把超长主题直接塞进一次调用。

导出保留作者、时间、楼层、回复关系、原帖链接和完整 Markdown 正文，包括引用。附件保留引用，不下载二进制。若论坛没有返回原始 Markdown，则使用纯文本并明确显示格式缺失数量。隐藏、删除、系统楼层等未返回内容计入排除数量；账户验证消息替换为隔离提示。不能读取的内容不宣称已读。

新增回复不会自动加入正在进行的任务，需重新发起。导出是读取时的快照，修改过的正文不会自动同步。最多100,000个楼层 ID、16 MiB正文，超限明确失败，不能下载成“完整导出”。下载复核公开性及每批源楼层可见性；来源撤回、会话失效或传输中断时缺少完成标记，网页拒绝保存该不完整文件。

原始 Markdown 读取使用 Discourse 的 `include_raw` 参数，接口依据：[Discourse TopicsController](https://github.com/discourse/discourse/blob/main/app/controllers/topics_controller.rb)。

## 用量与恢复

导出不调用模型。研究默认任务上限200,000 token，可在页面设为1,000–2,000,000；按实际用量结算，并始终受管理员全站每日预算约束。此上限与普通单主题回复额度分开；没有用原先个人记忆的小额度截断整帖。

原文、分段结果和最终正文加密保存，七天到期清理。每个账户最多30个保留任务、同时一个活动任务；全站最多两个排队/活动任务，单worker逐个处理。失败不自动再次付费，已完成片段保留。点击「手动继续」复用成功片段；停止不会撤销已经在途的计费调用。重启把未完成任务标为中断。达到本任务上限时需提高额度新建任务；仅每日额度不足可等预算重置后继续。

新建「整帖总结工作规则」「整帖点评工作规则」两个管理员模块，不改原人格。管理员可在提示词书架编辑，发布全局工作配置后用于新任务；未发布时使用内置规则。任务冻结已发布工作规则和人格版本；连接、个人编排或身份变化阻断继续，需新任务。

## 接口与权限

- `GET /api/topic-reviews`：本人七天内记录与用量；不返回原文。
- `POST /api/topic-reviews`：`{topic, mode: "export" | "review", focus, max_tokens}`，返回201及任务ID。
- `GET /api/topic-reviews/{id}`：进度和已完成结果；查看结果复核公开性与全部已读来源。
- `GET /api/topic-reviews/{id}/export?format=markdown|json`：完整原文下载。JSON结尾为 `complete: true`。
- `POST /api/topic-reviews/{id}/cancel`、`/resume`：停止或显式继续。

写请求要求同源和CSRF；任务只归创建者可见，包括其他管理员也不可读。仅访问已配置论坛的公开主题，拒绝外站网址、私信和受限分类；编辑者必须拥有经过私信核验的稳定论坛身份。使用机器人论坛凭据读取，但通过匿名读取或论坛明确的非受限分类元数据复核公开性，不因此把机器人可见的私密资料开放给用户。模型没有论坛发送能力、账户权限修改能力或其他人的私人记忆。

## 验证

`backend/tests/test_topic_review.py` 使用假论坛和模拟模型，覆盖全文、所有作者、长文末尾、加密、零调用导出、逐层汇总、断点、预算、CSRF/身份/所有者、隐藏源撤回、无自动重试与重启。PostgreSQL另验证并发创建只能一个成功及整帖预算不能超支。部署证据及模型实测范围见 [ACCEPTANCE.md](ACCEPTANCE.md)，模拟结果不冒充真实模型质量验收。
